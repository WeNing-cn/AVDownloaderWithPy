## 📖 项目简介

AVDownloader 是一款基于 Python + PyQt5 开发的视频爬取下载工具，支持对网站动态视频资源的自动爬取与本地保存。特别支持 M3U8 播放列表的 TS 分片自动合并、getmovie 链接的处理以及批量 URL 下载管理。

### ✨ 主要特性

- **🤖 自动下载模式**：一键自动探测并下载视频资源
- **📝 批量 URL 管理**：支持批量添加多个网址，每行一个 URL
- **🔄 智能重试机制**：下载失败自动重试，最多 5 次，指数退避
- **🎯 智能资源检测**：优先检测 getmovie 链接，其次检测 M3U8 文件
- **📊 实时状态更新**：下载失败或成功时立即更新状态
- **📜 下载历史记录**：避免重复下载已下载的网址
- **🧩 TS 分片处理**：自动下载、解密和合并 TS 格式视频分片
- **🖥️ 直观的用户界面**：基于 PyQt5 构建的现代化界面
- **📝 日志记录系统**：详细记录下载过程和错误信息
- **⏸️ 断点续传支持**：支持下载中断后恢复任务
- **🔒 Chrome 进程管理**：自动管理浏览器进程，防止残留
- **✅ URL 验证机制**：自动验证 URL 格式

## 🎯 核心功能详解

### 1. URL 列表管理

- **📥 批量添加 URL**：支持多行输入，每行一个 URL
- **🗑️ 删除 URL**：选中 URL 后点击"删除"按钮
- **🧹 清空列表**：点击"清空"按钮清空所有 URL
- **✅ 删除已成功**：删除所有下载成功的 URL
- **🔍 重复检测**：自动检测并跳过重复的 URL

### 2. 批量下载功能

**智能链接提取**：
1. 动态加载目标网页
2. 分析页面中所有链接的 URL 结构
3. 找出数量最多、结构最相似的链接组
4. 自动添加到下载列表

**使用步骤**：
1. 在输入框中粘贴视频选单页面 URL
2. 点击"批量下载"按钮
3. 程序自动分析并提取相似链接
4. 提取的链接自动添加到 URL 列表

### 3. 自动下载模式

**智能资源检测流程**：
1. **优先检测 getmovie 链接**：如有则使用特殊解密方法下载
2. **其次检测 M3U8 文件**：如有则自动下载 TS 分片
3. **否则标记为手动下载**：需要用户手动选择

**自动重试机制**：
- 分片下载失败时自动重试，最多 5 次
- 指数退避策略：1秒、2秒、4秒、8秒...
- 每次重试重新获取最新的动态资源链接
- 详细记录每次重试的状态

### 4. TS 分片处理

- **🧩 并行下载**：最多 8 个线程同时下载分片
- **🔐 加密处理**：支持 AES-128 解密（CBC 模式）
- **🎬 格式转换**：使用 FFmpeg 将 TS 分片合并为 MP4
- **⏸️ 断点续传**：支持下载中断后恢复

### 5. 进度与状态管理

- **📊 实时进度**：底部进度条显示下载进度
- **📝 详细日志**：控制台输出区域显示详细下载信息
- **🏷️ 状态显示**：每个 URL 旁边显示当前下载状态
- **⏸️ 断点续传**：支持下载中断后恢复任务

### 6. Chrome 进程管理

- **🧹 自动清理**：程序退出时自动终止所有 Chrome 进程
- **🔄 上下文管理**：使用 `with` 语句确保浏览器正确关闭
- **🛡️ 析构函数**：对象销毁时自动关闭浏览器

## 🛠️ 技术实现

### 核心技术栈

| 技术 | 用途 |
|------|------|
| **PyQt5** | 构建现代化的用户界面 |
| **Selenium + Chrome** | 浏览器模拟和动态资源加载 |
| **concurrent.futures** | 多线程并行下载 TS 分片 |
| **FFmpeg** | TS 分片合并为 MP4 |
| **requests** | HTTP 请求和密钥获取 |
| **pycryptodome** | AES-128 解密加密视频 |

### 核心模块

1. **MainWindow** (`main.py`)：主窗口类，负责界面管理和用户交互
2. **BrowserSimulator** (`browser_simulator.py`)：浏览器模拟器，支持上下文管理器
3. **VideoDetector** (`video_detector.py`)：视频检测器，识别和提取视频链接
4. **VideoDownloader** (`video_downloader.py`)：视频下载器，下载普通视频文件
5. **TSMerger** (`ts_merger.py`)：TS 合并器，下载、解密和合并 TS 分片
6. **DownloadStateManager** (`download_state_manager.py`)：下载状态管理器，支持断点续传

## ⚠️ 注意事项

### 依赖要求

1. **Chrome 浏览器**：用于 Selenium 浏览器模拟
2. **FFmpeg 工具**：用于 TS 分片合并，位于 `Dependence/ffmpeg.exe`
3. **Python 3.8+**：用于运行源代码

### 安全提示

1. **网络连接**：确保网络连接稳定
2. **网站限制**：部分网站可能对视频下载有限制
3. **权限问题**：确保程序有足够的权限访问保存路径
4. **版权尊重**：请遵守相关法律法规，尊重视频版权

### 常见问题

#### 1. 无法探测到视频资源
- 检查 URL 是否正确
- 确保网络连接正常
- 部分网站可能需要登录

#### 2. 下载失败
- 程序会自动重试 5 次
- 检查网络连接是否稳定
- 确保保存路径有足够的空间

#### 3. TS 分片合并失败
- 确保 FFmpeg 位于正确位置
- 检查 TS 分片是否全部下载成功

#### 4. 程序崩溃或无响应
- 确保已安装所有依赖库
- 对于大型视频，下载过程可能需要较长时间

#### 5. Chrome 进程残留
- 本版本已修复 Chrome 进程残留问题
- 程序退出时会自动清理所有 Chrome 进程
