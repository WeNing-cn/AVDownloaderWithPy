# 视频爬取下载程序开发方案

## 一、项目概述

AVDownloader 是一款基于 Python + PyQt5 开发的视频爬取下载工具，支持动态网页视频资源探测、M3U8 流媒体下载、TS 分片自动合并等功能。

## 二、项目结构

```
AVDownloaderWithQTCpp/
├── AVDownloader/              # 主程序目录
│   ├── main.py                # 主程序入口（GUI界面）
│   ├── browser_simulator.py   # 浏览器模拟模块（Selenium）
│   ├── video_detector.py      # 视频资源探测模块
│   ├── video_downloader.py    # 视频下载模块（HTTP请求）
│   ├── ts_merger.py           # TS分片合并模块（M3U8处理）
│   ├── download_state_manager.py  # 下载状态管理（断点续传）
│   ├── utils.py               # 工具函数
│   ├── requirements.txt       # Python依赖配置
│   └── build_exe.py           # 打包脚本
├── mobile/                    # 移动端版本（Kivy）
├── .github/workflows/         # CI/CD配置
├── README.md                  # 项目说明
├── LICENSE.md                 # 许可证
└── .gitignore                 # Git忽略配置
```

## 三、核心功能模块

### 1. 图形用户界面 (main.py)

- **技术栈**: PyQt5
- **功能**:
  - URL 列表管理（添加、删除、清空）
  - 批量下载控制
  - 实时进度显示
  - 日志输出控制台
  - 下载历史记录

### 2. 浏览器模拟模块 (browser_simulator.py)

- **技术栈**: Selenium + ChromeDriver
- **功能**:
  - 动态网页渲染
  - 网络请求捕获（性能日志）
  - M3U8/getmovie 链接探测
  - 上下文管理器支持（自动资源释放）

### 3. 视频资源探测模块 (video_detector.py)

- **功能**:
  - 分析页面 HTML 提取视频链接
  - 智能 URL 模式匹配
  - 批量下载链接提取（相似结构分析）

### 4. 视频下载模块 (video_downloader.py)

- **技术栈**: requests + concurrent.futures
- **功能**:
  - HTTP 视频文件下载
  - 多线程并行下载
  - 断点续传支持
  - 资源管理优化（Session复用）

### 5. TS分片合并模块 (ts_merger.py)

- **技术栈**: requests + FFmpeg + pycryptodome
- **功能**:
  - M3U8 播放列表解析
  - TS 分片并行下载（最多8线程）
  - AES-128 解密支持
  - 自动合并为 MP4
  - 失败重试机制（最多5次，指数退避）

### 6. 下载状态管理 (download_state_manager.py)

- **功能**:
  - 下载进度持久化
  - 断点续传支持
  - 已下载分片记录

### 2. 关键功能实现

#### 浏览器模拟
- 使用 Selenium WebDriver 启动 Chrome
- 启用性能日志捕获网络请求
- 支持无头模式运行
- 自动清理进程防止残留

#### 视频链接识别
- 监控网络请求捕获 M3U8/getmovie
- 解析页面 HTML 提取 `<a>` 标签链接
- 智能分析 URL 结构相似度
- 批量提取同类型视频链接

#### TS分片处理
- 解析 M3U8 文件获取分片列表
- 使用 ThreadPoolExecutor 并行下载（8线程）
- 支持 AES-128 解密（CBC模式）
- 使用 FFmpeg 合并分片为 MP4

#### 批量下载
- 动态加载目标网页
- 智能分析页面链接结构
- 提取相似度最高的链接组
- 自动添加到下载列表

## 六、技术难点及解决方案

### 1. 动态资源爬取
- **难点**: 网站使用 JavaScript 动态加载视频
- **解决方案**: 使用 Selenium 模拟浏览器，等待页面完全加载

### 2. 视频链接识别
- **难点**: 不同网站的视频嵌入方式不同
- **解决方案**: 
  - 网络请求捕获（M3U8/getmovie）
  - HTML 解析提取链接
  - 智能 URL 模式匹配

### 3. TS分片下载稳定性
- **难点**: 分片数量多，网络不稳定容易失败
- **解决方案**:
  - 并行下载提高效率
  - 失败重试机制（最多5次）
  - 指数退避策略（1s, 2s, 4s, 8s...）
  - 断点续传支持

### 4. 浏览器资源管理
- **难点**: Chrome 进程容易残留
- **解决方案**:
  - 上下文管理器（with语句）
  - 析构函数自动清理
  - 异常处理确保关闭

### 5. 批量下载闪退
- **难点**: 多线程资源竞争和内存泄漏
- **解决方案**:
  - 线程锁保护共享状态
  - Session 复用和及时关闭
  - 完善的异常处理

## 七、性能优化

1. **下载优化**
